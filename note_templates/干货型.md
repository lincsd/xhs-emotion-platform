# 干货型笔记模板

> 适用卡片类型：方法卡、公式卡、速算卡、概念卡
> 核心公式：痛点引入 → 系统知识点 → 口诀总结 → 收藏引导

## 模板结构

### 封面图
- 知识点总览/清单式标题
- "必背""必收藏""考前必看"等实用标签
- 清晰的数字化标题（8个技巧/5个公式/3步搞定）

### 轮播图编排（5-9张）
1. **封面图**：主题 + 数量 + 收藏引导
2. **知识点卡片 1-6**：每张一个知识点（使用已生成的卡片图）
3. **总结口诀**：所有口诀汇总
4. **收藏提醒**：考前翻出来看 + 系列预告

### 标题公式
- `[学段] + [主题] + [数量化] + [实用标签] + [emoji]`
- 例：`三年级数学｜8个速算技巧，考试至少快10分钟📝`
- 例：`小学数学公式大全｜一张图搞定所有面积公式📐`
- 例：`三下数学｜期末必考的6个易错点，收藏！⭐`

### 情绪曲线
```
焦虑/需求 → 获得感(逐个展示) → 满足/掌控 → 收藏冲动
```

### 评论区策略
- 置顶：补充更多技巧或易错点
- 引导："还想看哪个单元的整理？评论区告诉我"
- 系列化：暗示还有更多内容
