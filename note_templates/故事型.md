# 故事型笔记模板

> 适用卡片类型：生活卡、思维卡、对战卡
> 核心公式：生活场景 → 遇到问题 → 数学解决 → 触动共鸣

## 模板结构

### 封面图
- 场景化插图（辅导作业、超市购物、亲子互动）
- 共鸣式文案：真实感 + 情绪感
- "昨天...""你家孩子也这样吗？"

### 轮播图编排（4-6张）
1. **封面图**：场景 + 情绪 hook
2. **场景展示**：描述生活情境
3. **问题呈现**：遇到的数学问题
4. **解法揭示**：用卡片展示解法
5. **亲子互动**：带孩子试一试的引导
6. **系列预告**：日常里还有哪些数学

### 标题公式
- `[场景] + [转折/发现] + [情感共鸣] + [emoji]`
- 例：`昨天辅导作业差点崩溃…直到发现这个方法🤯`
- 例：`带孩子逛超市，她突然问了一个数学问题…`
- 例：`我和女儿的口算PK赛，结果我输了😅`

### 正文结构
```
[开头：场景带入]
昨天带娃去超市🛒
结账的时候，他突然问："妈妈，找零是不是算错了？"

[问题出现]
买了一个笔记本5元 + 铅笔3元5角
付了10元，收银员找了2元...

[思考过程]
等等！
5 + 3.5 = 8.5
10 - 8.5 = 1.5
应该找1元5角才对！

[解决 + 感悟]
原来孩子在学校学的"小数加减法"
居然用到了！👏
数学真的无处不在呀～

[亲子引导]
💡 建议爸爸妈妈们：
下次去超市，让孩子算找零
比刷100道题都管用！

[互动]
你家孩子有过这样的"数学时刻"吗？
评论区分享你们的故事💬

[标签]
#辅导作业 #亲子教育 #生活中的数学 #小学数学 #育儿日常
```

### 情绪曲线
```
代入感 → 好奇/紧张 → 恍然大悟 → 温暖感动 → 分享冲动
```

### 评论区策略
- 置顶：分享自己的类似经历
- 引导："你家孩子有没有让你惊喜的数学瞬间？"
- 情感共鸣比知识量更重要
