# 反差型笔记模板

> 适用卡片类型：陷阱卡、辨析卡
> 核心公式：设置认知冲突 → 暴露常见错误 → 揭示正确答案 → 引发讨论

## 模板结构

### 封面图
- 大字展示反直觉的题目或错误答案
- 配合"90%的人都做错了！""你确定你会？"等 hook
- 用红色❌/绿色✅制造视觉冲突
- 悬念感：答案不在封面上，引导翻页

### 轮播图编排（3-6张）
1. **封面图**：题目 + 强 hook
2. **错误展示**：最常见的错误做法 + ❌标记
3. **正确揭秘**：正确解法 + ✅标记 + 陷阱标注
4. **口诀总结**：一句话记住 + IP角色
5. **互动图**（可选）：类似题目，答案在评论区
6. **系列预告**（可选）：下一期预告

### 标题公式
- `[数字] + [身份标签] + [反常结论] + [emoji]`
- 例：`这道题90%的大人都做错了！三年级的你能对吗？😱`
- 例：`三年级数学｜看似简单却暗藏陷阱的5道题⚠️`
- 例：`别再这样教孩子了！这个方法一直是错的❌`

### 正文结构
```
[开头：制造冲突/设置悬念] 1-2句
昨天辅导孩子作业，一道"简单"的题把我难住了...

[展示题目]
题目：840 - 840 ÷ 4 = ?
你的答案是多少？先别看下面👇

[暴露错误]
❌ 很多人会这样算：
840 - 840 = 0，0 ÷ 4 = 0
答案是0？大错特错！

[揭示正确]
✅ 正确算法：
先乘除后加减！
840 ÷ 4 = 210
840 - 210 = 630
答案是630！

[总结口诀]
📝 记住：先乘除后加减，别被顺序骗！

[互动引导]
你做对了吗？评论区告诉我你的第一反应💬
觉得有用就收藏➕转发给需要的家长吧！

[标签]
#小学数学 #三年级数学 #数学陷阱题 #辅导作业 #学习方法
```

### 情绪曲线
```
好奇/自信 → 尝试(可能做错) → 震惊/意外 → 恍然大悟 → 分享冲动
```

### 评论区策略
- 置顶评论：放答案或额外知识点
- 引导话术："你家孩子做对了吗？""第一反应是多少？"
- 制造争议：故意放一个有争议的说法引发讨论
