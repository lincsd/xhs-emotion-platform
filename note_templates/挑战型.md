# 挑战型笔记模板

> 适用卡片类型：挑战卡、速算卡
> 核心公式：发起挑战 → 限时/限条件 → 公布答案 → 评级激励

## 模板结构

### 封面图
- 大字"挑战"/"PK"/"限时"等关键词
- ⏱️倒计时元素 + 难度星级
- "你能在30秒内全对吗？"等疑问句

### 轮播图编排（4-6张）
1. **封面图**：挑战宣言 + 规则说明
2. **题目页 1-3**：每页1-2道题，预留答题空间
3. **答案揭晓**：逐题答案 + 解析
4. **成绩评级**：全对=学霸 / 对3题=不错 / 对1题=继续努力
5. **系列预告**：下次挑战更难哦～

### 标题公式
- `[限时] + [挑战内容] + [激将法] + [emoji]`
- 例：`30秒5道题⏱️三年级口算挑战，你能全对吗？`
- 例：`小学数学速算PK｜看谁先算出来⚡`
- 例：`三年级数学闯关｜第3关难倒99%的孩子🏆`

### 正文结构
```
[开头：发起挑战]
⚡ 速算挑战来了！
准备好了吗？计时开始！⏱️

[规则说明]
📋 规则：
- 共5道题，限时30秒
- 不能用计算器！
- 截图你的用时发评论区

[给出题目]
① 24 ÷ 3 = ?
② 56 ÷ 7 = ?
③ 45 ÷ 9 = ?
④ 72 ÷ 8 = ?
⑤ 63 ÷ 7 = ?

[答案在图片里/评论区]
答案翻到下一页👉

[成绩评级]
5题全对 → ⚡闪电侠！
4题对 → 🌟很棒！
3题对 → 💪继续加油
≤2题对 → 📚回去练练

[互动]
你用了几秒？评论区打卡⏱️
@你的好朋友来PK！

[标签]
#口算挑战 #小学数学 #速算技巧 #限时挑战 #数学PK
```

### 情绪曲线
```
跃跃欲试 → 紧张计算 → 好奇对答案 → 得意/不服 → 分享PK
```

### 评论区策略
- 置顶：答案 + 评分标准
- 引导："我用了XX秒，你呢？"
- 邀请PK："@谁来挑战？"
