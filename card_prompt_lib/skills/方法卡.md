# 方法卡 Skill

> 适用于：计算方法、操作步骤、数据处理类知识点
> 典型知识点：口算、笔算、估算、验算、统计图制作、时间计算、搭配问题

## 🎯 教学目标
让学生 **看一道具体例题，就会做同类题**。

## 📐 设计策略

### 核心思路：具体例题 → 色块分步 → 答案
1. **必须有一道清晰的例题**（这是卡片灵魂！）
   - 题目大字醒目展示："840 ÷ 4 = ?"
   - 选最典型的一道，不要多题
   - 题目出自 JSON 数据中的 example.question

2. **关键一步用色块图示解释**（不是全过程！）
   - 口算除法：拆数法 → 色块分别计算 → 合并
     ```
     840 ÷ 4
     [红色块 800] ÷4= 200
     [蓝色块  40] ÷4=  10
     合并 → 210
     ```
   - 口算乘法：拆数法 → 3×5=15 → 补零 → 1500
   - 估算：找近似整十数 → 色块对比
   - 笔算：不画竖式！用色块拆分法
   - 验算：正反两种算法并排展示
   - 时间计算：时间轴/钟面图
   - 搭配问题：树形图/连线图

3. **答案 + 口诀**
   - 答案超大："= 210"
   - 口诀帮记忆方法

### 布局模板
```
[标题] ≤4字 + 学科标签
[例题] 白色卡片内，大字展示具体题目
[解法] 色块/图示分步（只展示关键1-2步）
[答案] 超大鲜明色 + 口诀便签
[小老师 + 气泡]
```

### 子类型设计指南

#### 🔢 口算类（除法/乘法）
- 核心技巧：**拆数法**
- 用2-3个不同颜色的色块表示拆开的数
- 每个色块旁标注计算结果
- 最后合并得到答案

#### 📐 估算类
- 核心技巧：**找近似数**
- 把原数和近似数并排，画箭头标"≈"
- 近似数用整十/整百的圆润数字

#### ✅ 验算类
- 核心技巧：**反向检验**
- 左右并排：原式 | 验算式
- 用相同颜色标注对应数字

#### ⏰ 时间计算类
- 核心技巧：**时间轴可视化**
- 画一条横轴，起点→终点，中间标注经过时间
- 或用钟面对比图

#### 🎯 搭配问题类
- 核心技巧：**有序罗列**
- 树形图：第一层选项 → 第二层选项 → 计数
- 用不同颜色区分不同组合

#### 📊 统计类
- 核心技巧：**图表 + 数据读取**
- 画简化版条形图
- 用箭头指出关键数据点

### ⚠️ 注意事项
- ❌ 不画完整竖式（拥挤、抽象）
- ❌ 不省略题目直接讲方法（没有上下文）
- ❌ 不写多于2步的解题过程
- ✅ 题目是核心！必须醒目可见
- ✅ 色块区分不同部分
- ✅ 答案要大要醒目
