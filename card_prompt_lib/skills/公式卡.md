# 公式卡 Skill

> 适用于：数学公式、判断规则类知识点
> 典型知识点：长方形面积公式、正方形面积公式、闰年判断规则

## 🎯 教学目标
让学生 **理解公式从哪来 + 记住怎么用**。

## 📐 设计策略

### 核心思路：图形实例 → 直观推导 → 公式
1. **一道应用例题**
   - "长8米宽5米的花坛，面积=?"
   - "边长6dm的正方形玻璃，面积=?"

2. **可视化推导（不是死记硬背！）**
   - 面积公式：在图形内画格子 → 数格子 → 长×宽就是格子总数
   - 正方形：正方形是特殊长方形 → 边长×边长
   - 闰年规则：用判断流程图（÷4 → ÷100 → ÷400）
   
3. **醒目公式 + 代入计算**
   - 公式用超大彩色字展示
   - 紧接着用例题数字代入："8 × 5 = 40平方米"

### 布局模板
```
[标题] ≤4字 + 学科标签
[例题] 白色卡片内，具体数字题目
[推导图] 可视化推导过程（格子图/流程图）
[公式] 超大醒目 + 代入计算 = 答案
[口诀 + 小老师]
```

### 子类型设计指南

#### 📐 面积公式类
- 画一个实际的长方形/正方形
- 内部画格子（用不同颜色标注长和宽方向）
- 格子总数 = 长 × 宽
- 公式用大号彩色框展示

#### 📅 判断规则类（闰年）
- 简洁判断流程图（从上到下）
- ÷4 → 能整除？ → ÷100 → 能整除？ → ÷400
- 每个节点用色块
- 最终结论：平年/闰年

### ⚠️ 注意事项
- ❌ 不只写公式不解释（死记硬背无用）
- ❌ 不写多个公式（一卡一公式）
- ❌ 推导过程不超过3步
- ✅ 公式从图形/实例中自然推出
- ✅ 公式字号最大，颜色最醒目
- ✅ 必须有代入计算（从抽象回到具体）
