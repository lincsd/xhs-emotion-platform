# 陷阱卡 Skill

> 适用于：反直觉题目、易错题、家长也做错的题
> 传播策略：激发「我居然做错了！」的惊讶情绪，家长自发转发考朋友

## 🎯 教学目标
让学生 **识别常见陷阱**，同时利用「先错后对」的反转感加深记忆。

## 📱 为什么在小红书传播广？

1. **家长做错 → 惊讶 → 转发考朋友**（裂变最强的情绪钩子）
2. **评论区自发争论**（算法推荐 = 更多曝光）
3. **"考考你"社交货币**（发到家长群/朋友圈）
4. **反直觉 = 记忆深刻**（教学效果也最好）

## 📐 设计策略

### 核心思路：设置陷阱 → 暴露错误 → 揭示真相

1. **封面：只放题目 + 悬念**
   - 大字题目："6 ÷ 2(1+2) = ?"
   - 钩子文案："90%的大人算错了！"
   - ❌ 封面不放答案（制造悬念）

2. **揭秘页：错误 vs 正确 并排**
   - 左侧 ✗ 大多数人的错误答案（红色，划掉）
   - 右侧 ✓ 正确答案 + 关键解释
   - **红圈圈出"陷阱点"**（一个就够）

3. **口诀页：防踩坑口诀**
   - 一句话记住如何避开这个坑
   - 小老师表情：😱（惊讶）

### 布局模板（单页版）
```
[标题] "⚠️ 陷阱！" + 话题（≤4字）
[大题目] 超大字展示题目（占20%，制造"你来试试"的感觉）
[钩子] "你的答案是___？" / "90%做错！"
[揭秘区] 左✗(红色大字错误答案) 右✓(绿色大字正确答案)
[关键点] 红圈标注陷阱所在 + ≤6字说明
[口诀] 防踩坑口诀（便签风）
[小老师] 😱惊讶表情 + "别踩坑！"
```

### 推荐陷阱题型

| 年级 | 陷阱题 | 错误率 | 陷阱点 |
|------|--------|--------|--------|
| 二年级 | 一个数×0=? | 极高 | 很多人答"那个数"而非0 |
| 三年级 | 0÷5=? 和 5÷0=? | 高 | 混淆"0除以"和"除以0" |
| 三年级 | 840-840÷4=? | 高 | 先算除法还是先算减法？ |
| 四年级 | 0.1+0.2=? | 高 | 很多人答0.3但计算机不这么想 |
| 五年级 | 1÷3×3=? | 极高 | 等于1还是0.999...? |
| 五年级 | 鸡兔同笼：8头26腿 | 中 | 用假设法还是列方程？ |

### ⚠️ 注意事项
- ✅ 题目必须是"看起来简单，做起来容易错"的
- ✅ 一卡一个陷阱（不要放多个）
- ✅ 钩子语气要挑衅但友好（"你能答对吗？"）
- ❌ 不要选太偏的题（要有共鸣感）
- ❌ 不要解释太多（揭秘要简短有力）
- ❌ 不要居高临下的语气

## 🎨 配色倾向
- **警告感 + 好奇心**
- 推荐：蜜桃橙渐变 或 亮红→暖橙渐变
- 标题用 ⚠️ 黄色警告色
- 错误答案：鲜红 #FF4757 + 划掉线
- 正确答案：翠绿 #2ED573
- 陷阱标注：红圈 #FF3838

## 🎯 情绪设计
- 封面情绪：**好奇+挑战**（"你来试试？"）
- 揭秘情绪：**惊讶+恍然大悟**（"原来如此！"）
- 小老师表情：😱→😏（从惊讶到得意）
