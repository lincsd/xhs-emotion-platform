# 挑战卡 Skill

> 适用于：限时挑战、闯关测试、互动问答
> 传播策略：「你能30秒内答对吗？」好胜心驱动互动→评论区争论→算法推荐

## 🎯 教学目标
通过游戏化挑战形式 **激发学生主动思考**，在"玩"中巩固知识。

## 📱 为什么在小红书传播广？

1. **互动率极高**：评论区写答案→互相纠正→算法判定为高互动内容
2. **好胜心驱动**：看到别人答对了，自己也想试
3. **系列粘性**：闯关设计→"第1关→第2关"→追更
4. **UGC二创**：家长拍孩子做题的视频发小红书

## 📐 设计策略

### 核心思路：限时 + 闯关 + 悬念答案

1. **题面页（主图）**
   - 大大的关卡编号："🏆 第7关"
   - 题目清晰醒目
   - 倒计时提示："⏱️ 30秒内答对算你赢！"
   - ❌ 不放答案！（答案在评论区/翻页）

2. **答案页（第2图或评论区）**
   - 正确答案 + 简短解析
   - 评价："答对了？你是数学小天才！"
   - 下一关预告："敢挑战第8关吗？"

3. **难度标识**
   - ★☆☆ 送分题 → ★★☆ 有点难 → ★★★ 学霸级

### 布局模板
```
[顶部] 🏆 关卡编号 + 难度星标
[大题目] 居中超大字展示（占30%）
[挑战元素] ⏱️ 30秒 / 🧠 动动脑
[选项区] A B C D 四选一（如适用）
[底部] "答案在评论区👇" / "翻到下一页→"
[小老师] 🤔思考表情 + "你行吗？"
```

### 推荐挑战题型

| 类型 | 适合年级 | 示例 | 互动设计 |
|------|---------|------|---------|
| 口算闪电战 | 2-3年级 | 连续5题口算，30秒内全对 | 计时挑战 |
| 找规律 | 3-4年级 | 1,4,9,16,__,36 | 填空互动 |
| 图形计数 | 3-5年级 | "这个图有几个三角形？" | 评论区争论数量 |
| 巧填运算符 | 3-5年级 | "3○3○3○3=24" | 评论区写解法 |
| 逻辑推理 | 4-5年级 | "A说B说谎，B说C说谎..." | 推理挑战 |
| 脑筋急转弯 | 全年级 | "什么时候1+1=1？" | 趣味互动 |

### ⚠️ 注意事项
- ✅ 题目一定要能引发讨论（有多种解法或容易答错的）
- ✅ 难度适中（太难没人做，太简单没互动）
- ✅ 答案设计在评论区（提升互动数据）
- ✅ 系列编号（#第N关）驱动追更
- ❌ 不要一次放多道题（一卡一挑战）
- ❌ 不要把答案放在同一张图上

## 🎨 配色倾向
- **游戏感 + 活力**
- 推荐：亮紫→蓝紫渐变(#a18cd1→#fbc2eb) 或 橙红渐变
- 关卡编号：金色 #FFD700 + 光晕
- 倒计时：红色脉冲感
- 选项框：圆角彩色卡片
- 整体风格：像一个小游戏界面

## 🎯 情绪设计
- 进入情绪：**跃跃欲试**（"来！试试！"）
- 过程情绪：**紧张+专注**（倒计时压力）
- 结果情绪：**成就感/不服气**（"我要再来一次！"）
