# 速算卡 Skill

> 适用于：巧算技巧、速算秘诀、比课本方法更快的计算法
> 传播策略：「比老师教的快10倍」的惊喜感，家长觉得"捡到宝"→收藏转发

## 🎯 教学目标
让学生掌握一种 **比常规方法更快更巧** 的计算技巧。

## 📱 为什么在小红书传播广？

1. **实用收藏**：家长觉得"这个技巧太牛了，收藏给孩子"
2. **惊喜感**："原来还能这样算！"
3. **即时验证**：可以当场试一下，成就感满满
4. **家长友好**：大人也能用（不限于小学）

## 📐 设计策略

### 核心思路：常规慢方法 → 速算技巧 → 结果一致！

1. **先展示一道具体题目**
   - "67 × 11 = ?"
   - 让人先尝试用常规方法

2. **对比区（核心！）**
   - 左侧🐢常规法：67×11 列竖式... 好慢
   - 右侧⚡速算法：6_7 → 6(6+7)7 → 737！
   - 用色块/箭头展示速算的关键步骤

3. **答案 + 验证**
   - 大字展示答案
   - "不信？用计算器验证！"

### 布局模板
```
[标题] "⚡速算" + 技巧名（≤4字）
[题目] 超大字展示具体计算题
[对比区] 左🐢慢方法(灰色/淡色) 右⚡快方法(彩色/高亮)
[速算步骤] 1-2步，色块标注关键操作
[答案] 超大字 + "3秒搞定！"
[口诀] 速算口诀（便签风）
[小老师] ⚡表情 + "秒算！"
```

### 推荐速算技巧

| 年级 | 速算技巧 | 惊喜度 | 方法 |
|------|---------|--------|------|
| 二年级 | 凑十法进位加 | ★★★ | 8+6→8+2+4→10+4=14 |
| 二年级 | 拆数法口算乘法 | ★★★ | 12×4→10×4+2×4=48 |
| 三年级 | 两位数×11 | ★★★★★ | 67×11→6(6+7)7=737 |
| 三年级 | 首同末合十 | ★★★★ | 23×27→2×3|3×7=621 |
| 四年级 | 25×任意数 | ★★★★ | 25×36→36÷4×100=900 |
| 四年级 | 平方差速算 | ★★★ | 19×21→(20-1)(20+1)=400-1=399 |
| 五年级 | 分数凑整法 | ★★★ | 1/2+1/3+1/6→3/6+2/6+1/6=1 |
| 五年级 | 乘法分配律巧算 | ★★★★ | 99×37→(100-1)×37=3663 |

### 子类型设计指南

#### ⚡ 口算加速类
- 核心：拆数凑整
- 色块展示拆的过程
- 对比：常规逐位算 vs 凑整一步到位

#### 🧮 乘法技巧类
- 核心：找规律/公式
- 用色块标注"位置关系"
- 动态展示数字如何移动/组合

#### 🎯 巧算类
- 核心：变换等式形式
- 用色块展示等价变换
- 强调"看起来复杂，换个角度超简单"

### ⚠️ 注意事项
- ✅ 必须有常规法 vs 速算法的对比（速算感才出来）
- ✅ 速算步骤 ≤ 2步（真的要"快"）
- ✅ 选最惊艳的例子（数字要选好看的）
- ❌ 不要选只能用于极少数字的技巧（要有普适性）
- ❌ 不要展示复杂公式推导（只展示"怎么用"）
- ❌ 常规法不需要完整展示，灰色/小字暗示即可

## 🎨 配色倾向
- **酷炫 + 速度感**
- 推荐：薄荷蓝渐变 或 蓝紫渐变(#667eea→#764ba2)
- 速算区：高亮黄/橙色边框
- 常规法区：灰色/淡色（暗示"慢"）
- 闪电⚡图标：亮黄 #FFD700
- 答案：大字+光晕效果

## 🎯 情绪设计
- 开头情绪：**好奇**（"还能这样算？"）
- 展示情绪：**震撼**（"太快了！"）
- 结尾情绪：**成就感**（"我也学会了！"）
- 小老师表情：😎 或 ⚡
