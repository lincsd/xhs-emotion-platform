# 辨析卡 Skill

> 适用于：易混淆知识点、常见错误辨析
> 典型知识点：商中间有0 vs 商末尾有0

## 🎯 教学目标
让学生 **一眼看出两个易混概念的区别在哪**。

## 📐 设计策略

### 核心思路：✓/✗ 并排对比 → 红圈标差异
1. **一道真实例题切入**
   - 选一道最容易做错的题："609 ÷ 3 = ?"
   - 大字醒目展示

2. **并排对比核心区（占 50%）**
   - 左边 ✗ 错误做法（红色边框/淡红底）
   - 右边 ✓ 正确做法（绿色边框/淡绿底）
   - **红圈圈出关键差异点**（只圈1个地方）
   - 差异点旁标注 ≤4字说明

3. **一句话总结区别**
   - 金句提炼本质差异："0不能省！"
   - 口诀帮记忆

### 布局模板
```
[标题] ≤4字 + "⚠️易错" 标签
[例题] 白色卡片内，大字展示
[对比区] 左✗右✓ 并排，红圈标差异点
[金句] "0不能省！" 超大字
[口诀 + 小老师]
```

### ⚠️ 注意事项
- ❌ 不超过1组对比（多了眼花）
- ❌ 差异点不超过1个（聚焦！）
- ❌ 不写长文字解释差异
- ✅ 红圈/红色箭头指向差异处
- ✅ 错误用 ✗ + 红色，正确用 ✓ + 绿色
- ✅ 对比区要大（占50%面积）
