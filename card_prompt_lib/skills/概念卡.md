# 概念卡 Skill

> 适用于：认知新概念、理解含义类知识点
> 典型知识点：面积的含义、小数的含义、认识方向、认识时间单位

## 🎯 教学目标
让零基础学生 **一眼理解一个新概念是什么**。

## 📐 设计策略

### 核心思路：生活场景 → 抽象概念
1. **选择一个生活中的实物/场景**（不是定义！）
   - 面积 → 一本书的封面 vs 一张桌子
   - 小数 → 超市价签 ¥3.5
   - 方向 → 早晨的太阳在东边
   - 24时 → 下午3点 = 15:00 的钟面

2. **用图说话，不用文字解释**
   - 一个大的生活场景图（占 45%+）
   - 图上标注关键信息（≤2个标注）
   - 从实物自然过渡到数学概念

3. **一句话概括**
   - 金句 ≤ 6字："面积=占多大"
   - 口诀 ≤ 10字

### 布局模板
```
[标题] ≤4字 + 学科标签
[生活场景大图] 实物/场景，标注清晰
[概念提炼] 一句金句（从图到概念的桥梁）
[口诀 + 小老师]
```

### ⚠️ 注意事项
- ❌ 不写教科书定义
- ❌ 不列多个概念（一卡一概念）
- ❌ 不用抽象符号代替实物图
- ✅ 图要大、清晰、一眼看懂
- ✅ 优先选孩子日常接触的场景
