# 思维卡 Skill

> 适用于：逻辑推理、找规律、数学思维训练题
> 传播策略：「聪明的孩子都会这道题」家长焦虑+期望→主动传播

## 🎯 教学目标
培养 **数学思维能力**，超越计算层面，训练逻辑推理和模式识别。

## 📱 为什么在小红书传播广？

1. **焦虑+期望**："别人家孩子都会，我家孩子不能落后"
2. **智力标签**：转发 = "我家孩子也聪明"
3. **解法惊艳**：好的思维题解法会让人"wow"
4. **老师推荐**：很多数学老师账号会推荐思维训练

## 📐 设计策略

### 核心思路：有趣的问题 → 可视化思维过程 → 优雅解法

1. **一个引人入胜的问题**
   - 不是单纯计算题，而是需要"想一想"的题
   - 最好有故事背景或趣味情境
   - 题面简单，解法巧妙

2. **思维过程可视化**（核心区别于其他卡型！）
   - 用图示展示"思考的路径"
   - 如：画表格列举→发现规律→得出结论
   - 或：假设法→画图验证→得出答案
   - 关键：展示的是"怎么想"而非"怎么算"

3. **优雅的结论**
   - 答案要有"啊哈！"感
   - 一句话点明思维方法

### 布局模板
```
[标题] 🧩 + "动动脑" / "巧解题"
[问题] 趣味情境+具体问题（占20%）
[思维区] 可视化思考过程（占45%）
  - 假设法：画图/列表
  - 规律题：前几项→标注规律→推出答案
  - 逻辑题：条件→推理链→结论
[答案] 大字答案 + "思维妙招"一句话
[小老师] 🧠表情 + "动动脑！"
```

### 推荐思维题型

| 类型 | 年级 | 示例 | 思维方法 |
|------|------|------|---------|
| 🐓🐇 鸡兔同笼 | 3-4年级 | "笼子里8个头26条腿" | 假设法/画图法 |
| 🔢 找规律 | 2-5年级 | "1,4,9,16,?,36" | 模式识别(平方数) |
| 🌳 植树问题 | 3-4年级 | "路长100m,每10m种一棵" | 端点分析(+1/-1) |
| 🤝 握手问题 | 4-5年级 | "5个人每两人握一次手" | 组合思维/画图 |
| ⏰ 追及问题 | 4-5年级 | "快的每分走80m,慢的60m" | 差距分析 |
| 🎲 排列组合 | 4-5年级 | "3件上衣2条裤子几种搭配" | 树形图/乘法原理 |
| 📊 等差数列 | 4-5年级 | "1+2+3+...+100=?" | 高斯求和/配对法 |
| 🔄 还原问题 | 3-5年级 | "结果是20,倒推原来是几?" | 逆向思维 |
| 🏆 最优策略 | 4-5年级 | "怎么称3次找出次品?" | 策略分析 |

### 思维可视化技巧

#### 📊 假设法可视化
```
假设全是🐓(8只):
  腿数 = 8×2 = 16条
  差: 26-16 = 10条
  每换一只🐇多2条腿
  → 🐇 = 10÷2 = 5只
```
用色块分步，每步一个颜色

#### 🔍 规律发现可视化
```
1  →  4  →  9  →  16  →  ?  →  36
1²    2²    3²    4²    5²    6²
                        ↑
                       =25!
```
在数字下方标注隐含规律

#### 🌳 画图法可视化
用实际的图（树/人/点）展示，标注关键数量关系

### ⚠️ 注意事项
- ✅ 题目要有趣味性（不是纯计算）
- ✅ 展示思维过程而非计算过程
- ✅ 解法要有"优雅感"（不是硬算）
- ✅ 适当标注"思维方法名称"（假设法/画图法/逆向思维）
- ❌ 不要选奥数竞赛级别的（太难吓跑人）
- ❌ 不要多种方法（一卡一种思维方法）
- ❌ 不要思维步骤超过3步

## 🎨 配色倾向
- **智慧感 + 清晰**
- 推荐：薰衣草紫渐变(#E8D5F5→#D9AAF5) 或 薄荷蓝渐变
- 思维步骤：每步不同颜色色块
- 关键发现：金色/亮黄高亮
- 推理箭头：虚线+标签
- 整体：清晰、有条理、"聪明感"

## 🎯 情绪设计
- 开头情绪：**好奇+挑战**（"这题你会吗？"）
- 过程情绪：**专注+思考**（可视化引导思路）
- 结尾情绪：**恍然大悟+成就**（"原来这样想！太妙了！"）
