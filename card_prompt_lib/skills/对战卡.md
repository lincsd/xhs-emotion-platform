# 对战卡 Skill

> 适用于：亲子互动PK、家长vs孩子、同学对战
> 传播策略：双人参与→拍视频二创→社交裂变→UGC内容

## 🎯 教学目标
通过 **亲子/同学对战** 形式，在玩中复习，让学习变成快乐记忆。

## 📱 为什么在小红书传播广？

1. **UGC二创王**：家长拍"我和孩子PK数学"的视频→二次传播
2. **亲子场景**：教育类账号最爱的互动形式
3. **社交裂变**：转发到家长群"你家娃能赢你吗？"
4. **停留时间长**：两个人一起看→停留时间数据好→算法推荐

## 📐 设计策略

### 核心思路：左右分栏 → 家长区/孩子区 → 同题PK

1. **分栏设计（核心！）**
   - 左栏 👨 "家长区"（蓝色调）
   - 右栏 👧 "孩子区"（粉色调）
   - 中间：VS 大字

2. **同一道题，不同难度**
   - 家长版稍难/变形（给面子但也要动脑）
   - 孩子版正常难度
   - 两个版本考察同一个知识点

3. **计分+结果**
   - 底部放计分框
   - "答对+10分，答错-5分"
   - "连续答对3题 = 🏆冠军"

### 布局模板
```
[顶部] 🆚 对战！+ 主题
[VS大字] 左👨家长 中VS 右👧孩子（占20%）
[题目区-左] 家长版题目（蓝色卡片）
[题目区-右] 孩子版题目（粉色卡片）
[底部] 计分栏 + "翻页看答案"
[小老师] 🎭裁判装 + "开始！"
```

### 推荐对战题型

| 知识点 | 家长版 | 孩子版 | 对战感 |
|--------|--------|--------|--------|
| 口算 | 78×6=? | 18×6=? | 都是乘法但数字不同 |
| 单位换算 | 3.5km=?m | 2000m=?km | 正反互换 |
| 时间 | 2时45分=?分 | 90分=?时?分 | 正反转换 |
| 分数 | 5/8+3/8=? | 1/4+1/4=? | 同类但难度不同 |
| 面积 | 长12宽8面积=? | 边长5面积=? | 长方形vs正方形 |
| 找规律 | 高级版序列 | 基础版序列 | 同类型不同难度 |

### 对战模式变体

#### 🎯 速度赛
- 同一道题，谁先算出来谁赢
- 适合口算类

#### 🧩 接力赛
- 第一题家长做→结果作为第二题孩子的已知条件
- 适合综合应用

#### 🎭 出题赛
- 家长出题给孩子，孩子出题给家长
- 适合概念理解类

### ⚠️ 注意事项
- ✅ 家长版不能太难（避免尴尬）
- ✅ 孩子版要让孩子有可能赢（建立信心）
- ✅ 颜色区分要明显（一眼看出哪边是谁的）
- ✅ VS感要强烈（对抗感 = 趣味）
- ❌ 不要让家长觉得在被考试（要fun不要stress）
- ❌ 不要题目太多（一次一组就够）
- ❌ 不要分栏太小看不清

## 🎨 配色倾向
- **对抗感 + 活力**
- 推荐：双色分栏
  - 家长区：蓝色调(#54A0FF→#2E86DE)
  - 孩子区：粉色调(#FF6B6B→#EE5A24)
  - VS：金色 #FFD700 + 火焰效果
- 背景：深色(#1a1a2e) 或 渐变紫(#2c003e→#12002e)（电竞感）
- 整体：像一个对战游戏的界面

## 🎯 情绪设计
- 开头情绪：**跃跃欲试**（"来和孩子比一下！"）
- 过程情绪：**紧张刺激**（"谁先算出来？"）
- 结尾情绪：**欢乐亲子**（"不管输赢都开心"）
