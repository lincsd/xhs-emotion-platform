# 生活卡 Skill

> 适用于：数学在生活中的应用场景、实用数学技巧
> 传播策略：「原来买菜也要用数学」实用+接地气，家长觉得教育有意义→分享

## 🎯 教学目标
让学生理解 **数学不是课本里的东西，而是每天都在用的工具**。

## 📱 为什么在小红书传播广？

1. **家长共鸣**："对！这个我天天遇到！"
2. **实用价值**：不只是应试，真的有用
3. **亲子场景**：带孩子去超市就能教数学
4. **破除焦虑**："原来学数学不是白学的"

## 📐 设计策略

### 核心思路：生活场景 → 数学问题 → 实用解法

1. **一个真实生活场景**（占40%）
   - 超市购物、做饭称量、出行路线
   - 用插画/照片风格，有烟火气
   - 场景中自然包含数学元素

2. **从场景中提取数学问题**
   - "苹果5元/斤，妈妈买了3斤半，给了20元，找多少？"
   - 问题要是孩子日常能遇到的

3. **场景中直接标注解法**
   - 在场景图上标注关键数字
   - 用气泡/便签展示计算过程
   - 答案与场景结合（"找回2.5元"）

### 布局模板
```
[标题] 🏠 + 场景名（"超市数学"/"厨房数学"）
[场景大图] 生活插画，占40%（超市/厨房/操场...）
[数学问题] 从场景中提取的具体问题
[解法] 在场景上标注+气泡计算
[结论] "找回2.5元" + 实用小Tips
[小老师] 🏠表情 + "数学在身边！"
```

### 推荐生活场景

| 场景 | 年级 | 数学知识点 | 题目示例 |
|------|------|-----------|---------|
| 🛒 超市购物 | 2-3年级 | 加减法/找钱 | "买了5元和3元的东西，给10元找多少？" |
| 🛒 打折计算 | 4-5年级 | 百分数/折扣 | "原价80元打7折，实付多少？" |
| 🍰 分蛋糕 | 3年级 | 分数初步 | "一个蛋糕分给4个人，每人几分之几？" |
| 🍳 做饭称量 | 3-4年级 | 克与千克 | "食谱要500g面粉，秤上显示0.4kg，还差多少？" |
| 🏃 操场跑步 | 3-4年级 | 周长/距离 | "操场一圈400米，跑3圈多少米？" |
| 🚗 出行时间 | 4年级 | 时间计算 | "8:30出发，路上1小时40分，几点到？" |
| 📐 装修量房 | 5年级 | 面积计算 | "房间长5m宽4m，铺1m²瓷砖要几块？" |
| 🎁 分糖果 | 2-3年级 | 除法/余数 | "23颗糖分给5个人，每人几颗？剩几颗？" |

### ⚠️ 注意事项
- ✅ 场景要真实、有生活气息（不要太抽象）
- ✅ 用孩子熟悉的场景（超市、学校、家里）
- ✅ 数字要真实合理（苹果单价不要100元）
- ✅ 解法要在场景中自然展示（不要脱离场景列算式）
- ❌ 不要变成纯应用题（要有场景氛围）
- ❌ 不要太多文字（场景图为主）

## 🎨 配色倾向
- **温暖 + 生活感**
- 推荐：暖黄渐变(#FFD89B→#FFA7A7) 或 暖绿(#a8e6cf→#dcedc1)
- 场景图：手绘插画风/水彩感
- 标注：气泡框，圆角卡片
- 数字：红色/橙色醒目标注
- 整体：温馨、有烟火气、像生活笔记

## 🎯 情绪设计
- 开头情绪：**熟悉感+亲切**（"这场景我见过！"）
- 过程情绪：**恍然大悟**（"原来这就是数学！"）
- 结尾情绪：**实用满足**（"下次买菜我也能用！"）
