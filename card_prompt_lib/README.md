# 知识卡片 Prompt 工程库

> 小红书风格 AI 知识卡片的完整 Prompt 沉淀，可复用、可追溯、可迭代。

## 📁 目录结构

```
card_prompt_lib/
├── README.md                          # 本文件 - 总览
├── CHANGELOG.md                       # Prompt 迭代日志
│
├── templates/                         # 通用模板
│   ├── system_prompt_v9.md            # 当前主 System Prompt（版本化）
│   └── image_prefix.md                # 图片生成前缀指令
│
├── skills/                            # 按题型的设计 Skill
│   ├── 概念卡.md                      # 概念认知类（面积含义、小数含义…）
│   ├── 方法卡.md                      # 计算/操作方法类（口算、笔算、估算…）
│   ├── 辨析卡.md                      # 易混淆对比类（商中间有0 vs 末尾有0…）
│   └── 公式卡.md                      # 公式/规则类（面积公式、闰年判断…）
│
└── prompts/                           # 实际生成的 Prompt 记录
    └── 数学_三下/                     # 按学科+年级+学期分目录
        ├── _index.json                # 索引：card_id → prompt文件 + 生成状态
        ├── 02_06_商末尾有0的除法.md   # 每张卡的实际 prompt
        ├── 05_04_乘法的验算方法.md
        └── ...
```

## 🎯 四种题型 Skill 速查

| 题型 | 数量 | 核心设计策略 | 典型知识点 |
|------|------|-------------|-----------|
| **概念卡** | 8张 | 生活场景图 → 抽象概念 | 面积含义、小数含义、方向认知 |
| **方法卡** | 21张 | 具体例题 → 色块分步 → 答案 | 口算、笔算、估算、验算 |
| **辨析卡** | 2张 | ✓/✗ 并排对比 → 圈出差异点 | 商中间有0 vs 商末尾有0 |
| **公式卡** | 3张 | 图形实例 → 推导可视化 → 公式 | 长方形面积、正方形面积 |

## 🔧 使用方式

1. 查看 `skills/` 下对应题型的 Skill 文档，了解该类卡片的设计要求
2. 运行 `generate_card_images.py` 自动生成 prompt 并保存到 `prompts/`
3. 每次生成会同步更新 `prompts/{学科}_{年级学期}/_index.json`
